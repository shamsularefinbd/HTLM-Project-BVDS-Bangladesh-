## 📖 About

BVDS was founded on **3rd March 2022** by **Shamsul Arefin** in the island region of Patuakhali district (known as *Sagarkanya*). The organization unites youth volunteers to bring positive change to rural Bangladesh through healthcare, education, and social development.

**Mission:** Stand beside people in times of need, protect the environment, and build an educated, child-marriage-free modern society.

**Vision:** A developed Bangladesh where no one dies without medical care and every village becomes a model village.

## 🩸 Key Programs

- **Blood Donation** — Regular campaigns & 24/7 emergency donor management
- **Forestation** — 5,000+ saplings planted annually; free sapling distribution
- **Child Marriage Prevention** — Grassroots awareness campaigns
- **Education Support** — School supplies, scholarships for meritorious students
- **Healthcare** — Free medical camps in rural areas
- **Water & Sanitation** — Tube-well installation and hygiene awareness
- **Food Security & Agriculture** — Modern farming training for rural farmers
- **Sports & Culture** — Youth tournaments and heritage preservation

## 🚀 Getting Started

Clone the repository and open `index.html` in your browser — no build tools required.

```bash
git clone https://github.com/your-username/bvds-website.git
cd bvds-website
# Open index.html in your browser
```

To deploy on GitHub Pages:

1. Go to your repository **Settings → Pages**
2. Set source to `main` branch, `/ (root)` folder
3. Save — your site will be live at `https://your-username.github.io/bvds-website`

## ✏️ Customization Notes

- Replace all `Images/` placeholder paths with your actual image files before deploying.
- The `Video/` folder references local `.mp4` files — upload them to the repo or use a video hosting service (YouTube embed recommended for large files).
- Update contact details in every `<footer>` and in `contact.html` if they change.
- The course chapters (`chapter_01.html` … `chapter_20.html`) linked in `popular-books.html` need to be created separately.
